## 6. Tindakan rutin

- [ ] Cek query baru di Search Console → tambahkan ke `keyword-map.md` bila relevan.
- [ ] Cek halaman yang posisinya 5–15 → pertimbangkan perbaikan konten/internal link.
- [ ] Balas semua ulasan Google baru dalam 48 jam.
- [ ] Unggah minimal 1 foto baru ke GBP.
- [ ] Cek broken link dan 404 baru.
- [ ] Pastikan NAP identik di situs, GBP, dan direktori.

## 7. Ambang peringatan

- CTR turun > 30% dua minggu berturut-turut → audit title/description.
- Posisi keyword utama turun > 3 peringkat → cek kompetitor dan indexing.
- Performance mobile < 90 → audit gambar/JS.
- Ulasan baru 0 selama 30 hari → jalankan kembali permintaan ulasan ke pelanggan.
